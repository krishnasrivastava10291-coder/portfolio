# Krishna Srivastava — Portfolio

A premium, responsive personal portfolio website focused on Full Stack/MERN development, DSA in Java and AI/ML.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save.

## Update later
- Replace/add projects in `index.html`.
- Add a resume PDF and link it from the hero section when your resume is ready.
- Update the Journey section as your education/internships progress.
